## Image Guidelines

### Recommended Formats

- **Photos**: JPEG (.jpg) for photographs
- **Graphics**: PNG (.png) for graphics with transparency
- **Icons**: SVG (.svg) for scalable icons (when possible)

### Optimization Tips

- Compress images using tools like TinyPNG or ImageOptim
- Use appropriate dimensions to avoid unnecessary scaling
- Consider WebP format for modern browsers (fallback to JPEG/PNG)
- Keep file sizes under 500KB for web optimization

### Accessibility

- Provide descriptive alt text for all images
- Ensure sufficient color contrast in graphics
- Consider how images appear to screen reader users
